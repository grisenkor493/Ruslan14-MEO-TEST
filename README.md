# Random Quote Generator

**Автор:** [Руслан Грищенко]

## Описание
«Random Quote Generator» — это десктопное GUI-приложение, написанное на Python с использованием библиотеки `tkinter`. Программа предназначена для генерации случайных цитат из встроенной базы данных. Пользователь может фильтровать цитаты по темам и авторам, добавлять новые цитаты, а также просматривать историю сгенерированных фраз. История сессий автоматически сохраняется в файл `history.json`.

## Функционал
* Генерация случайной цитаты с использованием модуля `random`.
* Динамическая фильтрация доступных цитат по **Автору** и **Теме**.
* Защита от ввода пустых строк при добавлении новых цитат (валидация).
* Сохранение и загрузка истории генераций с использованием формата JSON.
* Удобный пользовательский интерфейс с прокручиваемым списком истории.

## Примеры использования (Тесты)

**Тест 1: Генерация без фильтров**
1. Откройте приложение.
2. Убедитесь, что в фильтрах установлено "Все".
3. Нажмите "Сгенерировать цитату".
*Ожидаемый результат:* Появляется случайная цитата, запись о ней добавляется в историю и сохраняется в JSON.

**Тест 2: Фильтрация по автору**
1. В выпадающем списке "Фильтр по автору" выберите "Альберт Эйнштейн".
2. Нажмите "Сгенерировать цитату".
*Ожидаемый результат:* Генерируются только цитаты Эйнштейна.

**Тест 3: Проверка валидации при добавлении**
1. Оставьте поле "Текст" пустым, введите случайные данные в "Автор" и "Тема".
2. Нажмите "Добавить в базу".
*Ожидаемый результат:* Появление всплывающего окна с ошибкой ввода. База не обновляется.
